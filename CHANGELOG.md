# Changelog

All notable user-facing changes to OmaFrames are documented here.

## 0.5.0 - 2026-08-30

- Add the Vines window-decoration pack with theme-aware procedural foliage and
  clockwise growth.
- Add one global Chameleon actor with perimeter walking, inter-window jumps,
  reduced motion, and topology recovery.
- Add an Omarchy bar widget for native-host and per-pack controls.
- Add HyprPM packaging, ABI validation, clean unload behavior, and a diagnostic
  `hyprctl omaframes` command.
- Publish the first Omarchy marketplace-ready beta package.
